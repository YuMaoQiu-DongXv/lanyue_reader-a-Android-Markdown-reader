```glsl
// 施瓦西黑洞光线追踪
#version 330 core
uniform vec3 uCamPos;
const float RS = 1.0;      // 史瓦西半径

vec3 trace(vec3 pos, vec3 dir) {
    float h2 = length(cross(pos, dir));
    for (int i = 0; i < 256; i++) {
        float r = length(pos);
        if (r < RS) return vec3(0.0);
        vec3 acc = -1.5 * h2 * pos / pow(r, 5.0);
        dir += acc * 0.02; pos += dir * 0.02;
    }
    return texture(uSky, dir).rgb;
}
```

```python
def planck(lam, T):
    """黑体辐射谱亮度"""
    h, c, k = 6.626e-34, 3e8, 1.381e-23
    return (8 * math.pi * h * c / lam**5) / (math.exp(h * c / (lam * k * T)) - 1)
```

## 5. 公式【验收点：下面第 5.3 条上次显示成了红色报错原文】

### 5.1 行内公式

质能方程 $E = mc^2$，下标上标 $a_i^2$，希腊字母 $\alpha\beta\gamma\theta\lambda\pi$，
强调语法干扰项 $Projection*Rotation*Translation$（里面的 `*` 不能被当成斜体标记）。

### 5.2 行间公式

$$
u_{T}(\lambda)=\frac{8 \pi h c}{\lambda^{5}} \frac{1}{e^{\frac{h c}{\lambda k T}}-1}
$$

矩阵与括号：

$$
\begin{pmatrix} a & b \\ c & d \end{pmatrix} \qquad \left[ \frac{\partial f}{\partial x} \right]
$$

求和与积分：$\sum_{n=1}^{\infty} \frac{1}{n^2} = \frac{\pi^2}{6}$，$\int_{0}^{\infty} e^{-x^2}\,dx = \frac{\sqrt{\pi}}{2}$。

根式与连分式：$\sqrt[3]{x^2+y^2}$，$\dfrac{1}{1+\dfrac{1}{x}}$。

大型算子：$\bigcup_{i} A_i$、$\bigoplus$、$\oint_C$、$\lim_{x \to 0} \frac{\sin x}{x}$。

字体族：$\mathcal{L}$ $\mathscr{L}$ $\mathfrak{g}$ $\mathbb{R}$ $\mathsf{ABC}$ $\mathtt{abc}$ $\mathbf{XYZ}$
